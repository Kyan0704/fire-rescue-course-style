# 消防救援课程PPT — 完整风格规范

## 1. 画布与基础设置

| 参数 | 值 |
|------|-----|
| 幻灯片尺寸 | 13.33 × 7.5 英寸（16:9 宽屏） |
| 像素尺寸（96dpi） | 1280 × 720 px |
| 左右安全边距 | 0.83 英寸（约 80px） |
| 顶部安全边距 | 0.6-1.1 英寸 |
| 底部安全边距 | 0.5 英寸 |

## 2. 配色体系

### 2.1 主色板

```
┌─────────────────────────────────────────┐
│  #0A2A54  深蓝（主背景/品牌色）          │
│  RGB(10, 42, 84)                        │
├─────────────────────────────────────────┤
│  #FF6B00  消防橙（强调色/高亮）          │
│  RGB(255, 107, 0)                       │
├─────────────────────────────────────────┤
│  #121212  深黑灰（内容页背景）           │
│  RGB(18, 18, 18)                        │
├─────────────────────────────────────────┤
│  #1A1A1A  深灰（卡片背景A）              │
│  #1C1C1E  深灰（卡片背景B）              │
├─────────────────────────────────────────┤
│  #FFFFFF  白色（主标题文字）             │
│  #E5E7EB  浅灰（正文文字）               │
│  #D1D5DB  中灰（次级正文）               │
│  #9CA3AF  灰（注释/辅助文字）            │
└─────────────────────────────────────────┘
```

### 2.2 配色使用规则

- **封面/章节/结束页**：背景使用 `#0A2A54` 深蓝，叠加全屏背景图（透明度50-70%）
- **内容页**：背景使用 `#121212` 深黑灰
- **卡片容器**：使用 `#1A1A1A` 或 `#1C1C1E`，与背景形成微弱层次
- **卡片顶部装饰条**：使用 `#0A2A54` 深蓝，高度0.1英寸
- **强调元素**：章节标签、关键数据、图标高亮使用 `#FF6B00` 消防橙
- **文字层级**：标题白色 `#FFFFFF` → 正文浅灰 `#E5E7EB` → 注释灰 `#9CA3AF`
- **分隔线**：白色 1pt 细线，或 `#FF6B00` 橙色短线（装饰用）

### 2.3 禁用配色

- 禁止使用纯白背景（`#FFFFFF` 仅用于文字）
- 禁止使用高饱和度的红、黄、绿作为大面积填充
- 禁止超过3种颜色同时出现在一个页面（除图片外）

## 3. 字体规范

### 3.1 字体家族

| 语言 | 字体 | 备选 |
|------|------|------|
| 中文 | Noto Sans SC（思源黑体） | 微软雅黑 / 思源黑体 |
| 英文/数字 | Poppins | Arial / Helvetica |

### 3.2 字号层级

| 层级 | 字号 | 字重 | 颜色 | 用途 |
|------|------|------|------|------|
| H0 封面标题 | 40-48pt | Bold | #FFFFFF | 封面主标题 |
| H1 章节标题 | 36pt | Bold | #FFFFFF | 章节过渡页大标题 |
| H2 页面标题 | 20pt | Bold | #FFFFFF | 内容页顶部标题 |
| H3 卡片标题 | 20pt | Bold | #FF6B00 / #FFFFFF | 卡片内标题 |
| H4 小标题 | 18pt | Bold | #FFFFFF | 子模块标题 |
| Body 正文 | 14-16pt | Regular | #E5E7EB | 段落正文 |
| Caption 注释 | 12-14pt | Regular | #9CA3AF | 图注、来源、备注 |
| Label 标签 | 14-20pt | Bold | #FF6B00 | CHAPTER标签、分类标签 |

### 3.3 排版规则

- 行间距：1.3-1.5倍
- 段落间距：段后6-8pt
- 字间距：默认
- 对齐方式：标题居中/左对齐，正文左对齐，避免两端对齐
- 每页文字总量：正文不超过100字，要点不超过5条

## 4. 布局网格系统

### 4.1 12列网格

- 总宽度：13.33英寸
- 左右边距：各0.83英寸
- 内容宽度：11.67英寸
- 12列，每列约0.84英寸，列间距0.2英寸

### 4.2 常用布局尺寸

| 布局 | 列数 | 宽度 | 间距 |
|------|------|------|------|
| 全宽 | 12列 | 11.67" | - |
| 半宽（2栏） | 6列 | 5.6" | 0.47" 间距 |
| 三分之一（3栏） | 4列 | 3.6" | 0.43" 间距 |
| 四分之一（4栏） | 3列 | 2.8" | 0.27" 间距 |

### 4.3 标准位置坐标

以英寸为单位（左上角原点）：

- **页面标题**：left=0.83, top=0.6~1.1, width=11.67, height=0.7
- **内容区域顶部**：top=1.8~2.2
- **内容区域底部**：top≤6.8
- **左栏**：left=0.83
- **右栏（2栏布局）**：left=6.9
- **卡片高度（2×2）**：2.2英寸
- **卡片高度（4列）**：4.2英寸

## 5. 组件规范

### 5.1 卡片（Card）

- 填充：`#1A1A1A` 或 `#0A2A54`
- 圆角：小圆角（0.1-0.2英寸）或直角
- 可选顶部装饰条：高度0.1英寸，`#0A2A54` 或 `#FF6B00`
- 内边距：左右0.3英寸，上下0.25英寸
- 阴影：无（扁平化设计）

### 5.2 图标（Icon）

- 尺寸：0.3-0.7英寸（方形）
- 风格：线性图标或面性图标，统一风格
- 颜色：白色 `#FFFFFF` 或消防橙 `#FF6B00`
- 位置：卡片左上角，与标题对齐
- 与文字间距：0.2英寸

### 5.3 分隔线（Divider）

- 装饰短线：长度1.1-1.4英寸，高度0.02英寸，白色或橙色
- 全宽分隔线：长度=内容宽度，高度0.01英寸，白色30%透明度
- 位置：标题下方0.2英寸处

### 5.4 图片（Image）

- 内容配图：圆角矩形，无边框
- 全屏背景图：覆盖整页，叠加50-70%透明度深蓝遮罩
- 卡片内图片：顶部铺满，高度约2.5英寸
- 图片与文字间距：0.2-0.3英寸

## 6. 动画与切换（可选）

- 页面切换：淡入淡出（Fade），0.5秒
- 内容动画：擦除（Wipe）或浮入（Fly In），从下方
- 动画顺序：标题 → 图片 → 卡片依次出现
- 避免使用花哨的3D旋转、弹跳等动画

## 7. 内容风格指南

### 7.1 标题撰写

- 页面标题用陈述句或疑问句，概括本页核心观点
- 示例："为什么需要无人机参与消防救援？"
- 避免："第二部分 概述" 这类无信息量标题

### 7.2 正文撰写

- 每条要点控制在1-2行
- 用"动词+名词"结构，如"提高救援效率"
- 关键术语首次出现时加粗或用橙色标注
- 数据优先：用具体数字代替模糊描述

### 7.3 课程叙事结构

标准课程PPT推荐结构：
1. 封面（课程名 + 演讲者）
2. 目录（5个章节）
3. 章节一过渡页
4. 章节一内容页（3-5页）
5. 章节二过渡页
6. ...
7. 总结页
8. 结束/致谢页
